# SmartNotes-LLM-Notebook
SmartNotes LLM Notebook is a fully offline, multi-agent AI pipeline that converts any lecture video, audio file, or PDF local or from YouTube into a structured, bilingual, publication-ready PDF study guide. It runs entirely on local hardware using Gemma 4 (google/gemma-4-E2B-it) with no cloud dependency and no data leaving the device.
